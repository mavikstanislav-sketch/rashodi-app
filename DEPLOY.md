# Как разместить приложение в интернете (доступ с ПК и телефона)

Всё, что можно было подготовить в коде, уже сделано. Ниже — то, что нужно
сделать вам самим (регистрация на сторонних сервисах и оплату/данные карты
я вводить не могу).

Понадобится два бесплатных аккаунта:

1. **Turso** — облачная база данных (замена локального файла), карта не нужна.
2. **GitHub** — чтобы хранить код и подключить его к хостингу.
3. **Render** — хостинг, на котором будет работать сам сайт (можно войти через GitHub).

## Шаг 1. Создать бесплатную базу данных на Turso

1. Откройте [turso.tech](https://turso.tech) и зарегистрируйтесь (проще всего — через GitHub).
2. В панели создайте новую базу данных (Create Database), любое имя, ближайший регион.
3. Откройте созданную базу и скопируйте:
   - **Database URL** — начинается с `libsql://...` — это `TURSO_DATABASE_URL`.
   - Создайте токен доступа (обычно кнопка **Create Token** / **Generate Token**) —
     это `TURSO_AUTH_TOKEN`. Скопируйте его сразу, повторно он может не показываться.

Сохраните оба значения — они понадобятся на шаге 3.

## Шаг 2. Загрузить код на GitHub

1. Зайдите на [github.com](https://github.com) и создайте новый пустой репозиторий
   (New repository), например `rashodi-app`. Не добавляйте README/gitignore при
   создании — они уже есть в проекте.
2. В папке проекта на своём компьютере выполните:

   ```bash
   git init
   git add .
   git commit -m "Учёт личных расходов"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/rashodi-app.git
   git push -u origin main
   ```

   (Если хотите, чтобы это сделал я — просто попросите, и я выполню `git init`/`commit`
   локально; сам пуш на GitHub всё равно потребует вашего логина в git-провайдере.)

## Шаг 3. Развернуть на Render

1. Зайдите на [render.com](https://render.com) и войдите через GitHub.
2. **New +** → **Web Service** → выберите репозиторий `rashodi-app`.
3. Настройки:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free (или платный — по желанию, для скорости отклика)
4. В разделе **Environment** добавьте переменные:

   | Ключ | Значение |
   |---|---|
   | `NODE_ENV` | `production` |
   | `SESSION_SECRET` | любая длинная случайная строка (придумайте сами) |
   | `TURSO_DATABASE_URL` | значение из шага 1 |
   | `TURSO_AUTH_TOKEN` | значение из шага 1 |

5. Нажмите **Create Web Service** и дождитесь окончания сборки (несколько минут).
   Render выдаст адрес вида `https://rashodi-app.onrender.com` — уже с HTTPS.

Готово — этот адрес открывается и с компьютера, и с телефона (из любой сети).

## Шаг 4. Открыть как приложение (не просто вкладку браузера)

Приложение поддерживает установку (PWA) — иконка появится как у обычного
приложения, откроется в отдельном окне без адресной строки браузера:

- **Android (Chrome):** откройте сайт → меню (⋮) → «Установить приложение» /
  «Добавить на главный экран».
- **iPhone (Safari):** откройте сайт → кнопка «Поделиться» → «На экран “Домой”».
- **ПК (Chrome/Edge):** откройте сайт → значок установки в адресной строке
  (или меню → «Установить Мои расходы»).

## Важно знать про бесплатный тариф Render

- Сервис «засыпает» после ~15 минут без запросов и просыпается по первому
  обращению — первое открытие после паузы может занять до ~30–50 секунд.
  Это нормально, данные при этом не теряются (они хранятся в Turso, а не на
  диске Render).
- Сессии входа хранятся в памяти процесса — после «сна»/передеплоя нужно
  будет войти заново (email/пароль), но сами расходы, карты и бюджет никуда
  не денутся.
- Если захочется убрать паузы — на Render есть платный тариф без «сна»
  (от ~$7/мес), либо можно взять другой хостинг (Fly.io, Railway и т.п.) —
  код это не затрагивает, так как БД уже вынесена в Turso.

## Проверка, что всё работает

После деплоя откройте выданный Render адрес в браузере и войдите демо-доступом
(`demo@example.com` / `demo1234`), либо зарегистрируйте свой аккаунт — данные
всех пользователей теперь хранятся в Turso и не пропадут при перезапуске сервиса.
